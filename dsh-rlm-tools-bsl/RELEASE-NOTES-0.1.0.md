# dsh-rlm-tools-bsl v0.1.0

Первый выпуск: MCP-сервер **rlm-tools-bsl** поднимается вместе с DSH и гасится вместе с ним — со вкладкой состояния и ручным управлением.

## Возможности

- **Жизненный цикл вместе с DSH** — сервер стартует при запуске DSH (после MCP-рукопожатия) и завершается деревом процессов при остановке DSH; порт освобождается. Никакой службы Windows и автозапуска «навсегда».
- **Вкладка «rlm-tools-bsl» в настройках** — секция в `settings.section`: статус, версия, pid, время работы, кнопки «Запустить / Остановить / Перезапустить», настройки запуска, хвост лога.
- **Подхват внешнего процесса и takeover** — если сервер уже отвечает на порту, второй не поднимается, а существующий гасится при выходе DSH (по MCP-рукопожатию отличает свой сервер от чужого; `/health` у rlm-tools-bsl отдаёт generic `{"status":"ok"}`).
- **Диагностика занятого порта** — видно имя и pid чужого процесса, есть кнопка «Освободить порт» с подтверждением (никогда не убивает автоматически).
- **Готовый JSON для MCP-менеджера** — вкладка показывает сниппет с кнопкой «Скопировать»; подключение выполняет штатный MCP-механизм DSH (`dsh-mcp-manager` или строка `@deepseek-ai/dsh-mcp-client` в профиле). Инструменты: `mcp__rlm__rlm_start`, `mcp__rlm__rlm_execute`, `mcp__rlm__rlm_help`, `mcp__rlm__rlm_projects`, `mcp__rlm__rlm_index`, `mcp__rlm__rlm_end`.
- **Portable-режим** — `RLM_CONFIG_FILE` / `RLM_INDEX_DIR` через поле переменных окружения; рабочий каталог (для `.env`) настраивается.
- **Роуты `/rlm/*`** — состояние, лог, автопоиск пути к исполняемому файлу, запуск/остановка/перезапуск, сохранение настроек, освобождение порта.

## Прочее

- Внешних зависимостей нет: host-часть на `node:*`, клиентская — на React из профиля DSH.
- Порт по умолчанию — 9330 (у самого rlm-tools-bsl 9000, который часто занят).
- Требуется dsh ≥ 0.1.2-rc.1 (слот `settings.section`) и установленный `rlm-tools-bsl` (Python 3.10+, `uv tool install rlm-tools-bsl`); подходит и `dsh web`, и DSH Desktop.
- E2E хост-части без DSH: `node dsh-rlm-tools-bsl/tests/_http.mjs` — мок `ctx.webServer` и настоящий сервер rlm-tools-bsl (25+ проверок жизненного цикла).

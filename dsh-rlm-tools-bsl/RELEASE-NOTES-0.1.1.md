# dsh-rlm-tools-bsl v0.1.1

Исправления по итогам установки на машине с файловой песочницей DSH.

## Изменения

- **Подсказка при недоступном каталоге логов** — если rlm-tools-bsl завершается с кодом 1 из-за `PermissionError` на `…\.config\rlm-tools-bsl\logs`, текст ошибки во вкладке дополняется объяснением и способом обойти: разрешить путь или задать `RLM_CONFIG_FILE` и `RLM_INDEX_DIR` в переменных окружения плагина.
- **Несостоявшийся запуск больше не показывается как «работает»** — при ошибке запуска (нет файла, нет прав) состояние сразу переходит в ошибку с текстом причины, без ожидания 30-секундного таймаута.
- **README**: установка и обновление rlm-tools-bsl (повторный `uv tool install` не обновляет установленный пакет — нужен `uv tool upgrade`; проверка версии `rlm-tools-bsl --version` ≥ 1.35), раздел «Данные и файловая песочница» (куда сервер пишет и как перенаправить), уточнён порт для проверки `/rlm/state` (веб-UI DSH, а не порт MCP-сервера), варианты файла MCP-менеджера (`mcp-servers.json`/`serverName` и `dsh-mcp.json`/`name`), служба Windows (включая тип запуска «Автоматически»).

## Прочее

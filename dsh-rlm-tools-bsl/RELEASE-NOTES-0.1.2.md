# dsh-rlm-tools-bsl v0.1.2

Автоустановка сервера: если rlm-tools-bsl в системе нет, плагин ставит его сам.

## Изменения

- **Автоустановка при запуске** — если команда не найдена, плагин ставит rlm-tools-bsl через uv в папку `$DSH_HOME/rlm-tools-bsl`: `bin` — исполняемые файлы (`rlm-tools-bsl.exe`, `rlm-bsl-index.exe`), `tool` — окружение инструмента, `python` — Python, если подходящего системного нет. Когда в системе нет и uv, он ставится в тот же `bin` официальным скриптом без изменения PATH. Ключ `autoInstall: false` в строке плагина выключает автоустановку.
- **Состояние «устанавливается rlm-tools-bsl…»** во вкладке; вывод установки и текст ошибок — в хвосте лога.
- **Поиск команды расширен**: PATH → `%USERPROFILE%\.local\bin` → собственная папка `bin`; при запуске и перезапуске проверка идёт без кэша (установка сервера вручную подхватывается сразу).

## Прочее

- Сценарий «чистая машина» для проверки автоустановки: `node tests/_clean-install.mjs` — изолированный `DSH_HOME` без uv и rlm-tools-bsl; плагин ставит uv, затем сервер, и поднимает его (6 проверок, качает ~60 МБ).
- E2E хост-части: 26 проверок (`node dsh-rlm-tools-bsl/tests/_http.mjs`).
- Требуется dsh ≥ 0.1.2-rc.1 и Node.js ≥ 20; для автоустановки — сеть и PowerShell (Windows).

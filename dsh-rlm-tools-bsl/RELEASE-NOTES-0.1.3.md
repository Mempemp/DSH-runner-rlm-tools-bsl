# dsh-rlm-tools-bsl v0.1.3

Автопрописка сервера в менеджер MCP: шаг «Add» вручную больше не нужен.

## Изменения

- **Автопрописка в хранилище менеджера MCP** — при первом успешном запуске сервера плагин добавляет запись `rlm` в файл установленного менеджера: `dsh-mcp-manager` → `$DSH_HOME/mcp-servers.json` (поле `serverName`), `@wingsky-1/dsh-mcp-manager` → `$DSH_HOME/dsh-mcp.json` (поле `name`). Оба менеджера перечитывают свой файл на ходу — сервер подключается без перезапуска DSH.
- **Запись ведёт плагин** — при смене порта URL в записи обновляется, посторонние записи в файле сохраняются, повторные запуски дублей не создают. Ключ `mcpAutoRegister: false` в строке плагина отключает поведение.
- **Результат виден во вкладке** — в блоке «Подключение к DSH»: добавлено / обновлено / уже прописано, с путём к файлу, либо текст ошибки записи.

## Прочее

- E2E хост-части: 31 проверка (`node dsh-rlm-tools-bsl/tests/_http.mjs`), включая автопрописку в оба хранилища, сохранность чужих записей и идемпотентность повторного запуска.
- Сценарий «чистая машина»: `node dsh-rlm-tools-bsl/tests/_clean-install.mjs` (6 проверок).
- Требуется dsh ≥ 0.1.2-rc.1 и Node.js ≥ 20.

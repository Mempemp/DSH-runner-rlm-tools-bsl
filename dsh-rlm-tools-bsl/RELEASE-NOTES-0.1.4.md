# dsh-rlm-tools-bsl v0.1.4

Выпуск под rlm-tools-bsl 1.39.0: проверенная версия сервера названа в README и добавлено предупреждение о пересборке индексов.

## Изменения

- **Проверено на rlm-tools-bsl 1.39.0** — сервер обновлён с 1.35.1 (`uv tool upgrade`), E2E хост-части прогнан против настоящего 1.39.0. Кода плагина выпуск не касается: версия поднята вместе с версией сервера, на которой плагин проверен.
- **README: требования и пример статуса** — «нужна версия ≥ 1.35; проверено на 1.39.0», статус вкладки в примере — «работает (pid …, v1.39.0)». Нижняя планка совместимости не менялась.
- **README: предупреждение о пересборке индексов** — обновление 1.37 → 1.38 и выше поднимает схему индекса (`BUILDER_VERSION` 15 → 16): сборка, сделанная прежней версией, уходит в полную пересборку при первом обращении к проекту, а сессию, открытую до неё, нужно переоткрыть. Пересборка разовая и идёт на каждый проиндексированный каталог.

## Прочее

- E2E хост-части: 31 проверка (`node dsh-rlm-tools-bsl/tests/_http.mjs`), прогон на rlm-tools-bsl 1.39.0 — включая автопрописку в оба хранилища менеджера MCP и подхват внешнего процесса.
- Требуется dsh ≥ 0.1.2-rc.1 и Node.js ≥ 20.

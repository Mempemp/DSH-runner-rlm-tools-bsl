# dsh-rlm-tools-bsl v0.1.6

Сервер перестаёт «светиться отключённым» в панели менеджера MCP сразу после старта DSH.

## Изменения

- **Пересмонтирование записи после готовности сервера** — менеджер MCP судит запись один раз:
  пока открыто его окно загрузки, он ждёт поверхность инструментов и, не дождавшись, оставляет
  сервер неподключённым. Python-сервер отвечает позже этого окна (процесс поднимается около десяти
  секунд), поэтому в панели он выглядел выключенным, а подключение срабатывало только по кнопке.
  Теперь плагин после готовности сервера просит менеджер пересмонтировать запись через его сервис
  `mcpManager` — состояние пересчитывается само. Уже подключённую запись не трогаем: если менеджер
  сообщает `connected`, запрос не отправляется.
- **Сервис необязателен** — если менеджера нет или он старой версии без `mcpManager`, плагин
  работает как раньше: без сервиса и без ошибок.
- **Тест синхронизации** — `node tests/_manager-sync.mjs`: три сценария (холодный запуск с застрявшим
  вердиктом на настоящем `rlm-tools-bsl`, подхват внешнего процесса с вердиктом `connected`,
  отсутствие сервиса). Пересмонтирование проверяется по свежему состоянию сервера в момент вызова.

## Прочее

- `clientInfo.version` в рукопожатии MCP приведён к версии пакета (был 0.1.4 при пакете 0.1.5).
- README: раздел автопрописки дополнен описанием пересмонтирования.
- E2E хост-части: 31 проверка (`node tests/_http.mjs`), раскладки хранилища — 4 сценария
  (`node tests/_mcp-store.mjs`).
- Требуется dsh ≥ 0.1.2-rc.1 и Node.js ≥ 20.

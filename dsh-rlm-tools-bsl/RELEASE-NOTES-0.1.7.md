# dsh-rlm-tools-bsl v0.1.7

Выпуск под rlm-tools-bsl 1.42.0: проверенная версия сервера названа в README, предупреждение о
пересборке индексов описывает новую схему.

## Изменения

- **Проверено на rlm-tools-bsl 1.42.0** — сервер обновлён с 1.39.0 (`uv tool upgrade`), E2E
  хост-части прогнан против настоящего 1.42.0: `31/31 проверок пройдено`. Кода плагина выпуск не
  касается: версия поднята вместе с версией сервера, на которой плагин проверен.
- **README: требования и пример статуса** — «нужна версия ≥ 1.35; проверено на 1.42.0», статус
  вкладки в примере — «работает (pid …, v1.42.0)». Нижняя планка совместимости не менялась;
  плагин не зависит от набора хелперов или формы ответов, поэтому несовместимые изменения самого
  сервера (1.40 — точные имена объектов, 1.41 — выбор доменов при старте, 1.42 — граф вызовов и
  `find_unresolved_calls`) его не касаются.
- **Предупреждение о пересборке индексов переписано под 1.42.0** — схема индекса выросла до v17:
  до полной пересборки `rlm_start` предупреждает и перечисляет, чего в индексе нет (граф не видит
  запусков процедур по имени и вызовов через коллекцию менеджера, аудит `find_unresolved_calls`
  недоступен); сама пересборка ускорилась примерно вдвое. Историческая справка про 1.38
  (схема 15 → 16) сохранена — сборка любой прежней версии уходит в пересборку целиком.

## Прочее

- Стенды `tests/_mcp-store.mjs` и `tests/_manager-sync.mjs` называют в рукопожатии ту же версию
  сервера, что README (`1.39.0` → `1.42.0`).
- E2E хост-части: 31 проверка (`node tests/_http.mjs`), раскладки хранилища — `node tests/_mcp-store.mjs`.
- Требуется dsh ≥ 0.1.2-rc.1 и Node.js ≥ 20.
